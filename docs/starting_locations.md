# Fixing missing EMV starting locations

## What’s missing

NYC **EMS Incident Dispatch Data** (`76xm-jjuj`) is generated by CAD. For privacy (HIPAA),
incident locations are aggregated (ZIP / borough / dispatch area). The extract also does
**not** include the latitude/longitude of the ambulance (or the station) at the moment of
assignment. That means you get travel time labels without a true origin node — a blocker for
route reconstruction and for supervised travel-time models that need OD geometry.

Chosen companion layers (OSM + LION) describe the street network, not where each deployed
unit started.

## What we do instead

In `src/emvro/depots.py` + `src/emvro/csl.py`:

1. **Destination** ≈ centroid / representative point of the incident ZIP from **MODZCTA** (`pri4-ifjk`).
2. **Borough prior** from `incident_dispatch_area` prefix (`B/X` Bronx, `K` Brooklyn, `M` Manhattan, `Q` Queens, `S/R` Staten Island), falling back to the incident `borough` field.
3. **Preferred static starts** ≈ nearest of:
   - **EMS/ambulance station** (`ji82-xba5`, ambulance / EMS station factypes)
   - **Hospital bay** (`ji82-xba5`, `HOSPITAL` / `ACUTE CARE HOSPITAL` only — excludes clinics). Tagged `nyc_hh_hospital_bay` vs `voluntary_hospital_bay` from `opname`.
4. **Fallback static start** ≈ nearest **FDNY firehouse** (`hc8x-tcnd`).
5. **Synthetic CSLs** ≈ FDNY **alarm-box** intersections (`v57i-gtxb`) in the highest-volume ZIPs per borough (EMS demand weights). ZIP-centroid CSLs are the fallback if alarm boxes are missing.
6. **`start_mode=hybrid`** (default): use the CSL when it is closer to the destination than the best static depot (proxy for an already-on-the-road / post-coverage unit); otherwise use the static depot.
7. Persist `start_source`, `depot_layer`, `start_mode`, `depot_name`, and `crow_flies_km`.

## Limits (be honest in the ASI notebook)

- Inferred starts are **not** ground-truth CAD unit GPS.
- Alarm-box CSLs approximate dispatcher Cross Street Locations; they are not an official CSL list.
- Hospital rows are acute-care facilities, not a verified “ambulance bay polygon” layer.
- Crow-flies nearest depot ignores one-way streets and real dispatch policy.

## CLI

```bash
python scripts/download_datasets.py --limit 5000
python scripts/build_od_pairs.py --start-mode hybrid   # or static | csl
```
